Ask a language model. It will answer.

First registry record filed. Nothing published. The model answers with identical confidence.

The insight

It is not a reasoning failure. It is a provenance failure.

What this does not do

A system that will not say what it cannot do has not earned the right to say what it can.

  • ✕It is not a regulatory decision. FDA review is a human, deliberative process with access to the confidential IND that CLARITY by construction cannot see.
  • ✕It only knows what is public. The dominant reason a Phase 1/2 asset scores low is that its own clinical data has not been published. That is a statement about the evidence, not the science.
  • ✕It does not match patients to trials. The catalog carries no site or eligibility geography — building a screening widget on data we do not have would be the exact failure the rest of the system exists to prevent.
  • ✕Small n on benchmarks. Six reviews is a position, not a distribution, and the interface says so out loud instead of drawing a histogram from six points.
  • ✕The reviewer is a model. The rubric, the weights, the phase gates and the guardrails are code. The judgement inside a domain is Claude's — and the proof chain exists precisely so you can overrule it.

Why it holds up under someone who knows the field

The parts that must not be a model's opinion are not one.

The rubric is arithmetic

Ten weighted dimensions, scored 1–5 against explicit anchors. Weights sum to 1.0, and the module refuses to load if they do not. Long-term genetic risk and biodistribution carry as much weight as CMC — for an in vivo editor those dimensions are the review.

The domains are phase-gated

Nine CLARITY domains, each activating at preclinical, Phase 1, 2 or 3. A preclinical asset is never asked for postmarketing controls it cannot have. Runtime policy, not documentation — they ship with the deployment.

Every run leaves a record

An audit record per run, and an optional full trace with prompts, structured outputs, timing and token usage. Reviews are deduplicated in flight, so a double-click never pays twice.

It degrades honestly

No canvas context, the flat SVG topology renders instead. No EventSource, the run says so rather than hanging. Read-only filesystem, the review is kept in memory rather than lost. Nothing fails silently.

61 tests covering the API surface, citation grammars, evidence assembly, traces, run guards and the whole render path.
